# KBM BLOCKER

<img width="531" height="377" alt="image" src="https://github.com/user-attachments/assets/d687401e-aa8c-43df-b00a-fe5003bd9f2e" />


Software Tool that allows you to block and unblock your KBM (Keyboard and Mouse) with key combinations like Ctrl + K (to block/unblock keyboard) and Ctrl + N (to block/unblock your mouse), this is useful if you have stupid annoying ppl around you or if you want to left your pc/laptop far away for a while and avoid stalkers/spies in ur environment.

# Guide installation
You can download or extract this file by using the command:
git clone https://github.com/MrJackzzOnTop/kbm_blocker

or just download it as zip.

# How to use?
If you are using linux, it is recommended to install python, open the terminal and just run:

python kbm_blocker-linux.py (IT WORKS ON WINDOWS ALSO)

But if you are using windows and you dont want to install/use python for this program, you can just download and open the .exe file on Releases category.
